Lovasnapló (app)

Készítette: Novoszáth Édua Luca - Q42VUH

Feladat leírása: Ez egy lovas edzésnapló alkalmazás.
Ebben a programban lehet rögzíteni egy adott ló(Hope) heti edzéseinek számát és ezeknek az összesített percét,
ellenőrzi az ideális heti terhelést (ami heti 3 lemozgatás),valamint kiszámítja a következő lehetséges 
edzés dátumát.

Modulok és függvények: 
`tkinter` (tanult modul): `Tk()`, `StringVar()`, `mainloop()`, `ttk.Label()`, `ttk.Entry()`, `ttk.Button()`, `messagebox.showinfo()`
`datetime` (bemutatandó modul): `date.today()`, `timedelta()`, `strftime()`
`lovas_NE` (saját modul): `terheles_ellenorzes_NE()`

Osztály(ok):
`Lo_NE` (a `lovas_NE` modulban) , `edzeshozzaadas()` metódus
